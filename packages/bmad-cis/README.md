# BMAD Creative Intelligence Suite package

MAIster packaging of
[BMAD CIS](https://github.com/bmad-code-org/bmad-module-creative-intelligence-suite)
`v0.3.2` at commit `97298b22fee1c7e482710d3a8414adb5cfccccd9`.

It contains four upstream creative workflows, one internal runtime-support
skill, and six platform agents under `maister-agents/`. `cis-discovery` is a
governed RAH flow: four read-only persona children publish typed contributions,
an orchestrator collects them, and one writer produces the reviewed brief.

See [the package reference](../../docs/bmad-cis/README.md). Upstream content
remains under the MIT license in `capability/reference/LICENSE.bmad`.
