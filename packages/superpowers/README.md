# Superpowers package

MAIster packaging of [obra/superpowers](https://github.com/obra/superpowers),
vendored from upstream `v6.3.0` at commit
`b36e0829c6d0140e93cfef2ca599b1b07d4a7797`.

The package ships all 14 upstream skills and four MAIster flows: `sp-dev`,
`sp-debug`, `sp-plan`, and `sp-execute`. All four publish typed results for
parent orchestrators. Inside each graph, structured handoffs carry exact design
and plan pointers, verification evidence, diagnoses, and review findings while
the implementation remains in one governed writer worktree.

See [the package reference](../../docs/superpowers/README.md) for the flow map
and MAIster-specific adaptations. Vendored upstream content remains under the
upstream MIT license in `capability/LICENSE.superpowers`.
